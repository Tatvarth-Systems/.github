# Tatvarth Systems — .github

An engineering company building software for operations that can't afford to be wrong.

This repository contains organization-level configuration for [Tatvarth Systems LLP](https://tatvarthsystems.com).

- `profile/README.md` — powers the public-facing profile shown on our GitHub organization page.
- `public/logo/` — master logo assets.
- `SECURITY.md`, `SUPPORT.md`, `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md` — default community health files, inherited by every repository in the organization that does not define its own.
- `.github/ISSUE_TEMPLATE/`, `.github/PULL_REQUEST_TEMPLATE.md` — default issue and pull request templates.
